1. **While music is actively playing**, press **Volume Up** all the way. Android keeps media volume separate from ringtone/call volume.
2. Go to **Settings → Sound & vibration → Volume** and push **Media** to maximum.
3. If they're Bluetooth headphones, open **Settings → Connected devices → your headphones** and look for anything like **Media volume sync / Absolute volume / HD audio**.
4. The big one: enable **Developer options** and test **Disable absolute volume**.  
   Go to **Settings → About phone → Build number**, tap it 7 times, then **Settings → System → Developer options → Disable absolute volume**. Toggle it, reconnect the headphones, and test again. Some Bluetooth headphone/Android combinations get substantially more usable range this way.
5. Also check whatever music app you're using for **volume normalization / loudness normalization / ReplayGain**. Spotify, for example, can deliberately reduce output level depending on the setting.

One warning: don't defeat every volume limit and then run headphones at max continuously; the REVVL isn't necessarily limiting volume arbitrarily—some of that is hearing protection.
